Timesheets

  • Select a project, then create a new timesheet to set the active job for this tablet.
  • The active timesheet is where new worker clock-ins go; only one timesheet can be active per tablet.
  • Switching the active timesheet does not clock anyone out. It only changes where new clock-ins go.
  • To clock workers in at another project, create a new timesheet and set it as the active timesheet. New workers will be clocked in under that timesheet.
  • Use the filter to view Active (current), Inactive (other sessions), or All sessions for today.
