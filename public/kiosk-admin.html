Timesheets

  • Select a project, then create a new timesheet to set the active job for this tablet.
  • The active timesheet is where new worker clock-ins go; only one timesheet can be active per tablet.
  • Switching the active timesheet does not clock anyone out. It only changes where new clock-ins go.
  • To clock workers in at another project, create a new timesheet and set it as the active timesheet. New workers will be clocked in under that timesheet.
  • Use the chevron to open timesheet actions (assign, close, delete).
  • When the last punch clocks out, you’ll be prompted to close the timesheet. Closed timesheets are read-only.
  • Status pills: Complete means everyone is clocked out; Complete & Closed means an admin closed it.
  • Closed timesheets cannot be set active or assigned; delete is only available when there are zero time entries.
  • Auto clock-out closes open punches at org-local midnight, but it does not close the timesheet.
  • Use the filter to view Active (current), Inactive (other sessions), or All sessions for today.

Time Entries — Review Pills

  • Missing punches — the entry has zero punches recorded.
  • Hours mismatch — punch hours do not match entry hours.
  • Geofence flag — at least one punch or kiosk session violated the geofence.
  • Auto clock-out: Midnight auto-close — closed at org midnight for a prior-day open punch.
  • Auto clock-out: Catch-up auto-close — hourly catch-up closed a prior-day open punch.
  • Auto clock-out: Daily max hours — closed when daily hours limit was exceeded.
  • Auto clock-out: Weekly max hours — closed when weekly hours limit was exceeded.
  • Auto clock-out — auto clock-out recorded without a reason.
  • Needs review — fallback when no specific issue is detected.

Time Entries — Status Tags

  • In progress — the entry is still open.
  • Pending review — not yet field-reviewed (flagged or clean).
  • Approved as-is — field-reviewed with no flags.
  • Approved — field-reviewed with flags.
  • Modified — field-reviewed with edits.
  • Rejected — rejected during field review.
